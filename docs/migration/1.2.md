# Migrating to 1.2

1.2 adds no public API and removes none. It changes one behavior every
`Run` caller can observe. Decision record:
[`docs/decisions/caller-cancellation.md`](../decisions/caller-cancellation.md).

## A cancelled `Run` context concludes `cancelled` (130), not `failed` (2)

Applies to `evo.Run(ctx, ...)` and `Output.Run(ctx, ...)` when `ctx` ends
before the run's work finishes. `evo.Main` passes `context.Background()`,
so a CLI built on `Main` does not change.

**Before (1.1):** the run concluded `failed`, exit 2, with a
`context canceled` (or `context deadline exceeded`) problem. Queued Tasks
still ran.

**After (1.2):** the run concludes `cancelled`, exit 130.
`Conclusion.Explanation` is `by caller` or `deadline exceeded`. Running
Tasks are marked cancelled and queued Tasks resolve `not_started`.

If your code branches on the outcome of a cancelled run, branch on the
state:

```go
result := out.Run(ctx, run)
switch result.Conclusion.State {
case evo.StateCancelled:
	// ctx ended: client gone, deadline passed, or shutdown
case evo.StateFailed:
	// the work itself failed
}
```

`Result.Err` is unchanged: it is still whatever your run callback returned.

A `ctx` that ends after every Task has already finished no longer changes
the verdict; the completed run reports its own outcome.

## MCP API-062 applies from 1.2 pins

Review reports package-level `evo.Task`/`Group`/`Sequence`/`Fact`/`Warn`/
`Print*`/`Confirm` inside an Isolated Output's `Run` callback as API-062.
It fires for the current recommendation and pins at 1.2.0 or later, never
for a 1.0.x or 1.1.x pin.
