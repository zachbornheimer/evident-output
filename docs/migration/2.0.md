# Migration 2.0

Evident Output 2.0 is a new contract. The public surface is exactly the
tables in `CONTRACT.md`. This guide names 1.x symbols that 2.0 removes or
replaces so a consumer can search their tree and rewrite. Every name that
`CHANGELOG.md` lists as removed has a row below, enforced by
`TestMigrationGuideMapsEveryRemovedName`.

## Construction

| 1.x                                                                               | 2.0                                                                                                                    |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `evo.Init(Config{Title: ...})`                                                    | `os.Exit(evo.Main(evo.Config{}, run))` with `func run(ctx context.Context, r *evo.Run) error`                          |
| `Output.Run` / hosted `Init`                                                      | `evo.Execute(ctx, cfg, run)`                                                                                           |
| `Config.Title`                                                                    | `Config.Name`                                                                                                          |
| `Init`, `SetDefault`, `Default`, `DefaultConfig`, `Runner`, `Option`              | no package-level output; `Main` or `Execute` builds the one `Run` and `Config` holds every setting                     |
| `Close`, `Finish`, `Context`, `Err`, `Cancel`                                     | `Main` and `Execute` finish the run; cancel the `ctx` you pass to `Execute`; read `Result.Err` and `Result.Conclusion` |
| `Title`, `Stdin`, `To`, `AlsoWrite`, `Width`, `KeepLastLines`, `DryRun`, `Redact` | `Config.Name`, `Config.DryRun`, and `Config.Facades` (`Stdin`, `Stdout`, `Stderr`, `Terminal`, `Redactor`)             |
| `MaxEntities`, `MaxEvents`, `MaxEvidenceBytes`, `MaxFrameRate`                    | no knob; the bounds are fixed, only `Config.MaxConcurrency` remains                                                    |

`Init` is gone. Construction is `Main` (signals, returns an exit code) or
`Execute` (caller owns context and exit).

## Waiting and snapshots

| 1.x                                                                                                 | 2.0                                                                            |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| package-level `Wait` as a run closer                                                                | return from `run`; Evo waits for all declared work before it finishes          |
| `TaskHandle.Wait`, `GroupHandle.Wait`, `SequenceHandle.Wait`                                        | removed; order work with `After` and read a produced value with `Computed.Get` |
| `ErrWaitDeadlock`                                                                                   | no equivalent; nothing waits, so nothing can deadlock                          |
| `Snapshot` / `TasksSnapshot` as public inspection                                                   | `Result` and `Conclusion` after `Execute` returns                              |
| `TaskSnapshot`, `PlanSnapshot`, `ChangesSnapshot`, `MessageSnapshot`, `RenderPlain`, `PlainOptions` | `Result` and `Conclusion`; machine output is `Output` `JSON` or `JSONL`        |

`Wait` is removed from every type. The 1.x habit of closing a run by waiting
on the default output is replaced by returning from `run`. `Snapshot` is not
part of the 2.0 export surface.

## Groups and tasks

| 1.x                                                                                                                                                                                                                                                                                                                                                                                     | 2.0                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `GroupHandle` / `SequenceHandle` / `TaskHandle`                                                                                                                                                                                                                                                                                                                                         | `Group`, `Sequence`, `Task`                                                                             |
| quantity-first mutation verbs on Task                                                                                                                                                                                                                                                                                                                                                   | `evo.Effect(ctx, EffectSpec{Verb, Object, Quantity}, fn)` and `evo.File`                                |
| `Add`, `Remove`, `Push`, `Step`, `Affected`                                                                                                                                                                                                                                                                                                                                             | `evo.Effect` with `EffectSpec.Verb` and `EffectSpec.Quantity`                                           |
| `EffectAdd`, `EffectCreate`, `EffectDelete`, `EffectInstall`, `EffectPush`, `EffectRemove`, `EffectUninstall`, `EffectUpdate`, `EffectVerb`                                                                                                                                                                                                                                             | `Verb`, the closed set `Create`, `Update`, `Delete`                                                     |
| `EffectRecord`, `FactRecord`, `Record`, `RecordLabel`, `RecordName`, `TaxonomyRecord`                                                                                                                                                                                                                                                                                                   | recorded for you from `Effect` and `Fact`; read `Result`                                                |
| `Key`, `ID`, `Name`, `Label`, `Value`, `Field`                                                                                                                                                                                                                                                                                                                                          | the Task name is its identity; sibling names are unique per parent                                      |
| `Block`, `Blockf`, `Blocked`, `NotStarted`                                                                                                                                                                                                                                                                                                                                              | `evo.Refuse` (precondition stopped it); a predecessor that did not succeed leaves dependents NotStarted |
| `Failf`, `Failure`, `Error`, `Unwrap`                                                                                                                                                                                                                                                                                                                                                   | `evo.Fail(summary, opts...)` returns an error                                                           |
| `Done`, `Incomplete`, `Pending`, `Running`, `Empty`, `Determinate`, `Indeterminate`                                                                                                                                                                                                                                                                                                     | a Task ends by returning; `Task.Progress` reports progress                                              |
| `Bytes`, `BytesKind`, `ProgressKind`                                                                                                                                                                                                                                                                                                                                                    | `Task.Progress(completed, total)`                                                                       |
| `EntityState`, `EntityOption`, `MutationOption`, `StartPhase`, `ConclusionState`, `StateBlocked`, `StateCancelled`, `StateChanged`, `StateFailed`, `StatePlanned`, `StateReady`, `StateWarning`                                                                                                                                                                                         | `Outcome`: `Succeeded`, `Satisfied`, `Excluded`, `Refused`, `Failed`, `Cancelled`                       |
| `Resolution`, `ResolutionAlreadySatisfied`, `ResolutionExecuted`, `ResolutionNoWork`                                                                                                                                                                                                                                                                                                    | `Satisfied` (already true) or `Succeeded` (ran)                                                         |
| `ExitOK`, `ExitBlocked`, `ExitFailed`, `ExitCancelled`                                                                                                                                                                                                                                                                                                                                  | `Result.ExitCode`: 0, 1, 2, 130                                                                         |
| `Strict`                                                                                                                                                                                                                                                                                                                                                                                | no option; misuse is always recorded in `Result` with a remedy                                          |
| `ErrAlreadyResolved`, `ErrClosed`, `ErrConcurrentRunning`, `ErrDryRunDeclaredLate`, `ErrDuplicateKey`, `ErrDuplicateSiblingName`, `ErrInvalidProgress`, `ErrKeyAfterDefine`, `ErrLimitExceeded`, `ErrNoTaskContext`, `ErrNotStarted`, `ErrProgressRegression`, `ErrRenderer`, `ErrTaskClosed`, `ErrTerminalWithoutSink`, `ErrUnresolvedTask`, `ErrInvalidConfig`, `ErrBasisAfterDefine` | misuse is recorded in `Result` with a remedy and never crashes; no error value to match                 |
| `ProblemCodeDuplicateSiblingName`, `ProblemCodeVerificationUnsatisfied`                                                                                                                                                                                                                                                                                                                 | `evo.Code` on your own Problems; Evo's misuse remedies carry their own codes                            |

## Skipped work and reasons

| 1.x                                                                        | 2.0                                                                  |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `Skipped`, `Reason`, `ReasonOption`, `TaxonomyReason`, `ForSkip`, `OnTask` | `return evo.Exclude(reason, opts...)`; Excluded folds into one tally |
| `Kept`                                                                     | `Task.Verify`, which resolves the Task Satisfied without running it  |
| `ErrReasonSkipOnly`, `ErrReasonWrongTask`                                  | no equivalent; `Exclude` takes a plain reason                        |

## Evidence, output capture and files

| 1.x                                                                                                                                                       | 2.0                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `Capture`, `CaptureOption`, `CaptureStream`, `CaptureStreamCombined`, `CaptureStreamStderr`, `CaptureStreamStdout`, `MaxCaptureBytes`                     | `Task.Writer()` on `cmd.Stdout` and `cmd.Stderr`; the tail is bounded and redacted                                |
| `Evidence`, `EvidenceOption`, `EvidenceStream`, `EvidenceStreamCombined`, `EvidenceStreamStderr`, `EvidenceStreamStdout`, `EvidencePhase`, `TaskEvidence` | `Task.Writer()`; `ExecResult.Stdout` and `ExecResult.Stderr` for `Exec`                                           |
| `Basis`, `Fingerprint`, `FingerprintValue`, `FSPath`, `App`, `Value`                                                                                      | `FileSpec.Inputs`, `FileSpec.Values`, `ExecSpec.Inputs`, `ExecSpec.Values`                                        |
| `Files`, `FileSet`, `FileFS`                                                                                                                              | `evo.File` for each file, `evo.Patch` for a unified diff; `Facades.FS` in tests                                   |
| `ErrFilePathIsSymlink`, `ErrFilePathTypeMismatch`, `ErrFileSpecMissingPath`, `ErrFileUnmanagedContentsMissing`                                            | the error `File` returns, or misuse recorded in `Result`                                                          |
| `ErrExecExecutableNotFound`, `ErrExecSpecMissingExecutable`, `ErrExecOutputMissingAfterSuccess`                                                           | `ErrExecOutputMissing` for a declared Output that is absent; any other `Exec` failure is the error `Exec` returns |
| `ErrPatchBinaryUnsupported`, `ErrPatchDeleteUnsupported`, `ErrPatchMalformed`, `ErrPatchRenameUnsupported`, `ErrPatchUnsupported`                         | `ErrPatchDoesNotApply`, or the error `Patch` returns                                                              |
| `FSResource`, `LogicalResource`, `Resource`, `ErrInvalidResource`, `ErrNestedResourceAcquisition`                                                         | `EffectSpec.Path` (filesystem claim) or `EffectSpec.Resource` (a `string` name); setting both is misuse           |
| `ErrInvalidPartialEffect`, `ErrEffectCallbackMissing`, `ErrEffectObjectMissing`, `ErrEffectQuantityNotPositive`, `ErrEffectVerbInvalid`                   | `evo.Effect` and `evo.PartialEffect`; misuse is recorded in `Result`                                              |
| `ProcessCommand`, `ProcessOutcome`, `ProcessRunner`, `CommandSpec`                                                                                        | `ExecSpec` and `Facades.Process`                                                                                  |

## Problems, remedies and confirmations

| 1.x                                                               | 2.0                                                                       |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `Warn`                                                            | `Task.Problem(summary, opts...)`, which never ends the Task               |
| `Severity`, `SeverityError`, `SeverityWarning`, `ProblemSeverity` | no severity; a Problem is non-fatal and the return value sets the Outcome |
| `Location`, `SourceLocation`                                      | `evo.On("path:line:col")`                                                 |
| `Count`                                                           | `evo.Detail(text)`, or `EffectSpec.Quantity` for a mutation               |
| `Command`, `NextCommand`, `Label`                                 | `evo.Next(evo.Action{Command: []string{...}, Label: "..."})`              |
| `ConfirmDetail`                                                   | `evo.Detail(text)`, which is also a `ConfirmOption`                       |
| `AssumeYes`, `PolicyFlag`, `PolicyHint`                           | `evo.NonInteractive(argv...)` and `evo.Destructive()`                     |
| `Attachment`                                                      | `evo.Detail(text)`                                                        |
| `Pluralize`, `TruncateNames`, `DefaultVisibleNames`               | Evo pluralizes `EffectSpec.Object` and folds names itself                 |
