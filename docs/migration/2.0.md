# Migration 2.0

Evident Output 2.0 is a new contract. The public surface is exactly the
tables in `CONTRACT.md`. This guide names 1.x symbols that 2.0 removes or
replaces so a consumer can search their tree and rewrite.

## Construction

| 1.x                            | 2.0                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------- |
| `evo.Init(Config{Title: ...})` | `os.Exit(evo.Main(run))` with `func run(ctx context.Context, r *evo.Run) error` |
| `Output.Run` / hosted `Init`   | `evo.Execute(ctx, cfg, run)`                                                    |
| `Config.Title`                 | `Config.Name`                                                                   |

`Init` is gone. Construction is `Main` (signals, returns an exit code) or
`Run` (caller owns context and exit).

## Waiting and snapshots

| 1.x                                               | 2.0                                                             |
| ------------------------------------------------- | --------------------------------------------------------------- |
| package-level `Wait` as a run closer              | `Task.Wait`, `Group.Wait`, `Sequence.Wait` on the declared work |
| `Snapshot` / `TasksSnapshot` as public inspection | `Result` and `Conclusion` after `Run` returns                   |

`Wait` on a Task or container still exists as a method. The 1.x habit of
closing a run by waiting on the default output is replaced by returning
from `run`. `Snapshot` is not part of the 2.0 export surface.

## Groups and tasks

| 1.x                                             | 2.0                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| `GroupHandle` / `SequenceHandle` / `TaskHandle` | `Group`, `Sequence`, `Task`                                              |
| quantity-first mutation verbs on Task           | `evo.Effect(ctx, EffectSpec{Verb, Object, Quantity}, fn)` and `evo.File` |

## Output

| 1.x                                                                                           | 2.0                                             |
| --------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Option constructors (`To`, `Plain`, `AlsoWrite`, `KeepLastLines`, `Width`, `Clock`, `DryRun`) | `Config` fields (`Output`, `Facades`, `DryRun`) |
| `Human` as a profile name on Options                                                          | `Output` selector `Human`, `JSON`, `JSONL`      |

Search the 1.x column in this file, then rewrite to the 2.0 column. MCP
`evident_output_review` is the autofixer for remaining call sites.
