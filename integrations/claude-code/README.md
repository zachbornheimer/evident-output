# Claude Code integration — Evident Output

```bash
go install github.com/zachbornheimer/evident-output/cmd/evident-output-mcp@latest
evident-output-mcp config --client claude-code
```

Paste the printed JSON into Claude Code MCP settings (user or project `.mcp.json`).
